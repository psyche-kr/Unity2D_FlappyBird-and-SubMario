# FlappyBird-SubMario

2D 게임 두 개를 만들며 물리, 애니메이션, UI 흐름을 익힌 학습 프로젝트입니다. 씬과 코드는 `Assets/01. Flappy Bird`, `Assets/02. Sub Mario`로 나뉩니다.

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 6000.0.3f1 (2D) |
| 언어 | C# |

## 1. Flappy Bird

- 점프 키를 누르고 있는 동안 위로 올라가고, 놓으면 중력 가속도로 떨어집니다. 키를 누를 때와 뗄 때 서로 다른 효과음이 납니다.
- 벽은 4초마다 오른쪽에서 생성되고 높이는 -2 ~ 2 사이에서 무작위입니다. 점수는 생존 시간입니다.

## 2. Sub Mario

횡스크롤 플랫포머입니다. 제한 시간 안에 도착 지점까지 가는 게임이고, 목숨은 3개입니다.

- **플레이어** (`PlayerController`): 점프 조작감을 위해 두 가지를 넣었습니다. 바닥에서 떨어진 직후 0.15초 동안 점프할 수 있는 **코요테 타임**, 바닥에 닿기 직전 0.15초 안에 누른 점프를 기억해 두는 **점프 버퍼**입니다. 상태(`Playing`, `Dead`)로 입력을 막고, 바닥 접촉 여부와 속도에 따라 Idle, Run, Jump, Fall 애니메이션을 바꿉니다.
- **적** (`EnemyController`): 앞쪽 콜라이더가 지형에 닿거나, 앞쪽 아래 콜라이더가 지형에서 떨어지면(낭떠러지) 방향을 뒤집습니다. 체력 3이고, 처치하면 회전하며 튕겨 나가고 제한 시간이 2초 늘어납니다.
- **제한 시간** (`GameManager`): 30초에서 시작해 줄어들고, 과일(`Fruit`)을 먹으면 늘어납니다. 0초가 되거나 목숨이 모두 사라지면 게임 오버 팝업이 뜹니다.
- **총알 오브젝트 풀** (`ObjectPool`): 총알을 미리 만들어 두고 비활성 상태인 것을 꺼내 씁니다.
- **레벨 선택** (`LevelManager`, `LevelPanel`): 레벨마다 이름, 썸네일, 프리팹을 `LevelInfo`에 담아 목록으로 관리합니다. 선택한 프리팹은 `DontDestroyOnLoad` 싱글턴이 들고 있다가 게임 씬이 로드될 때 생성합니다. 최고 점수는 `PlayerPrefs`에 저장해 팝업으로 보여 줍니다.
